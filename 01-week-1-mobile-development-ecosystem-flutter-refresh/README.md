## Refleksi Pembelajaran

### 1. Kapan native lebih tepat dipilih daripada cross-platform?
Pendekatan *native* lebih tepat dipilih untuk aplikasi yang membutuhkan performa grafis dan komputasi tinggi (seperti game berat), akses mendalam ke fitur *low-level* hardware terbaru, atau skalabilitas enterprise skala besar yang menuntut keamanan ketat dan kontrol penuh terhadap memori sistem.

### 2. Bagaimana perubahan state berhubungan dengan widget tree dan UI deklaratif?
Dalam UI deklaratif, antarmuka adalah representasi langsung dari *state* (`UI = f(state)`), di mana perubahan nilai *state* akan memicu framework untuk membangun ulang (*rebuild*) bagian *widget tree* yang terdampak secara efisien tanpa harus memanipulasi elemen UI secara manual satu per satu.

### 3. Mengapa commit kecil dengan pesan jelas bermanfaat bagi pekerjaan tim dan portfolio?
*Commit* berukuran kecil dengan pesan yang deskriptif sangat bermanfaat untuk mempermudah proses pelacakan *bug* (*debugging*), mempercepat pemahaman rekan tim terhadap riwayat perubahan kode, serta mencerminkan profesionalisme dan kedisiplinan kerja dalam sebuah portofolio.
